# Чеклист: создание аккаунта и подключение API

Порядок проверен на проекте Ники — здесь он записан с учётом всех ошибок, на которых мы там споткнулись.

Всё делается под постоянным VPN, одна и та же страна на всех этапах.

---

## Этап 1. Подготовка

- [ ] **1.1. Включить VPN** и зафиксировать страну. Не менять её ни разу: смена страны на новом аккаунте вызывает проверку.

- [ ] **1.2. Завести почту** под аккаунт. Отдельную, не личную и не ту, что у Ники.

- [ ] **1.3. Приготовить телефон.** Реальный номер. Виртуальные и SMS-активаторы Instagram распознаёт.

  Один номер можно привязать к нескольким аккаунтам, но лучше использовать разные — связанные аккаунты платформа видит и при блокировке одного может задеть второй.

- [ ] **1.4. Выбрать ник.** Проверять занятость, открывая `instagram.com/ИМЯ` — если 404, свободен.

  Варианты под тематику:

  `tihie.mysli` · `bez.lishnih.slov` · `korotko.o.glavnom` · `mysli.na.chernom` · `pro.sebya.tekst` · `slova.kotorye.nuzhny`

  Хороший ник: без цифр, без подчёркиваний в конце, произносится вслух без объяснений.

---

## Этап 2. Регистрация

- [ ] **2.1. Зарегистрироваться с телефона**, через мобильное приложение — у веб-регистрации выше процент проверок.

- [ ] **2.2. Подтвердить почту и телефон.**

- [ ] **2.3. Аватар.** Для такого аккаунта хорошо работает простой знак: чёрный квадрат с белой буквой, или наоборот. Могу отрисовать тем же скриптом.

- [ ] **2.4. Описание профиля.** Лимит 150 символов. Например:

  ```
  Короткие мысли, которые стоит перечитать
  Новое дважды в день
  ```

- [ ] **2.5. СТОП. Пауза 24–48 часов.** Ничего не публиковать. Аккаунт, начавший постить сразу после регистрации, попадает под подозрение автоматически.

  В паузу: зайти пару раз, полистать ленту, подписаться на 5–10 тематических аккаунтов.

---

## Этап 3. Настройка профиля

- [ ] **3.1. Перевести в профессиональный аккаунт.**

  Настройки → Аккаунт → Переключиться на профессиональный → **Автор** (Creator) → категория `Цифровой создатель`.

  Facebook-страницу привязывать не нужно — при запросе пропустить.

- [ ] **3.2. Двухфакторная аутентификация.** Обязательно, через приложение-аутентификатор. Резервные коды сохранить.

- [ ] **3.3. Профиль должен быть публичным.** Настройки → Конфиденциальность → «Закрытый аккаунт» **выключен**.

  Без этого токен не выпустится: Meta генерирует маркеры только для общедоступных аккаунтов.

### Про метку ИИ — здесь иначе, чем у Ники

У Ники метка обязательна: там фотореалистичные изображения несуществующего человека, и без раскрытия это нарушение правил Meta.

Здесь **метка не требуется** — картинка это текст на однотонном фоне, никого не изображает и ввести в заблуждение не может. Ставить её не нужно.

## Этап 4. Доступ к API

Делать **после** двух недель прогрева, не раньше.

Приложение Meta переиспользуем то же — `nika-publisher`. Одно приложение обслуживает сколько угодно аккаунтов, для каждого просто выпускается свой токен.

- [ ] **4.1. Открыть** developers.facebook.com → приложение `nika-publisher`.

- [ ] **4.2. Роли в приложении → Роли → Добавить людей.**

  **Здесь главная ловушка.** В диалоге два блока:

  - вверху «Назначить роль»: Администратор / Разработчик / **Тестировщик** / Пользователь аналитики
  - ниже «Дополнительные роли для этого приложения»: **Тестировщик Instagram**

  Нужен **«Тестировщик Instagram»** — тот, что с иконкой Instagram в нижнем блоке. Верхний «Тестировщик» ищет пользователей Facebook, и Instagram-ник туда вписать нельзя: выдаст «does not resolve to a valid user ID».

  Вписать ник нового аккаунта → Добавить. Статус станет «На рассмотрении».

- [ ] **4.3. Принять приглашение** в самом Instagram под новым аккаунтом:

  Настройки → Безопасность → Приложения и сайты → Приглашения тестировщика → **Принять**

  Либо по прямому адресу: `instagram.com/accounts/manage_access/`

  Без принятого приглашения следующий шаг выдаст «Недостаточно прав для роли разработчика».

- [ ] **4.4. Проверить разрешения.** Instagram API → Настройка API для входа в Instagram → пункт 1.

  Обязательно должно быть **`instagram_business_content_publish`** — именно оно публикует. Если его нет, добавить через «Go to permissions and features».

  Токен выдаётся с тем набором, что активен на момент генерации: добавишь разрешение потом — придётся выпускать заново.

- [ ] **4.5. Залогиниться в Instagram под новым аккаунтом** в том же браузере.

  Кнопка генерации токена использует текущую сессию Instagram. Если в браузере открыта Ника — токен выпишется на неё. Facebook-сессию не трогать.

- [ ] **4.6. Сгенерировать токен:** пункт 2 «Сгенерируйте маркеры доступа» → «Добавить аккаунт» → Продолжить → разрешить доступ.

## Этап 5. Что прислать мне

```
IG_USER_ID=
IG_ACCESS_TOKEN=
```

**Важно про User ID.** Meta показывает рядом с токеном один идентификатор, но для публикации через `graph.instagram.com` нужен другой — тот, что возвращает запрос `/me`.

На Нике мы на этом споткнулись: присланный ID оказался Business Account ID для другого пути, и публикация падала бы с невнятной ошибкой доступа.

Поэтому просто пришли токен — правильный ID я вытащу сам одним запросом и проверю связку.

App ID и секрет приложения уже есть, они общие с проектом Ники.

## Чего не делать

| Действие | Последствие |
|---|---|
| Менять страну VPN | проверка аккаунта |
| Заходить без VPN с российского IP | блокировка сессии |
| Постить сразу после регистрации | подозрение на бота |
| Четыре поста в сутки на новом аккаунте | ограничение охватов |
| Сервисы накрутки | теневой бан |
| Закрытый профиль | токен не выпустится |
