# Threads: подключение публикации

Threads работает поверх того же приложения Meta, что и Instagram, но токен у него **свой**, отдельный. Здесь описан аккаунт `@mono.motiv`; для Ники всё то же самое, инструкция лежит в её проекте.

Домены Threads в России заблокированы так же, как остальные домены Meta — `meta_net.py` обходит это сам, VPN для публикации не нужен. VPN нужен только на этапах, где ты работаешь в браузере через интерфейс Meta.

---

## Этап 1. Профиль Threads (10 минут)

- [ ] **1.1.** Зайти в приложение Threads под аккаунтом `@mono.motiv`, создать профиль. Аккаунт Threads создаётся из существующего Instagram и отдельной регистрации не требует.

- [ ] **1.2.** Выложить один любой пост руками. Публиковать через API можно только после первой ручной публикации.

---

## Этап 2. Сценарий использования в приложении (15 минут)

Всё делается в [developers.facebook.com](https://developers.facebook.com) → приложение **nika-publisher**.

- [ ] **2.1.** В левом меню открыть **«Сценарии использования»** (Use cases).

- [ ] **2.2.** Нажать **«Добавить сценарий использования»** и выбрать **«Доступ к Threads API»** (Access the Threads API). Это отдельный сценарий, не тот, что уже подключён для Instagram.

- [ ] **2.3.** В настройках сценария включить разрешения:
  - `threads_basic` — чтение профиля, обязательное
  - `threads_content_publish` — публикация

  Остальные (`threads_manage_replies`, `threads_read_replies`, `threads_manage_insights`) не нужны.

- [ ] **2.4.** В разделе **«Настройки»** сценария указать **URI перенаправления OAuth**. Подойдёт `https://localhost/` — поле обязательное, но при генерации токена через интерфейс не используется.

Сценарий настраивается один раз на приложение. Если он уже подключён для аккаунта Ники, этот этап пропускается — добавить нужно только тестировщика ниже.

---

## Этап 3. Тестировщик (10 минут)

- [ ] **3.1.** В настройках приложения открыть **«Роли»** → **«Дополнительные роли»**.

- [ ] **3.2.** Добавить `@mono.motiv` как **тестировщика Threads**. Ищется по нику Threads — он совпадает с ником Instagram.

- [ ] **3.3.** Принять приглашение: зайти в Threads под этим аккаунтом → **Настройки → Аккаунт → Приглашения для веб-сайтов и приложений** → принять.

  Без принятого приглашения токен выдастся, но публикация будет отбиваться с ошибкой доступа.

---

## Этап 4. Токен и идентификатор (10 минут)

- [ ] **4.1.** В сценарии «Доступ к Threads API» найти блок генерации токена, выбрать аккаунт, нажать **«Создать маркер доступа»**.

- [ ] **4.2.** Скопировать токен целиком. Он начинается на `THQ...` или `THAA...` и живёт **60 дней**.

- [ ] **4.3.** Узнать идентификатор пользователя Threads — он **не совпадает** с ID Instagram:

  ```
  cd tools
  python threads_refresh_token.py --whoami <токен>
  ```

- [ ] **4.4.** Прописать в `.env`:

  ```
  THREADS_USER_ID=...
  THREADS_ACCESS_TOKEN=THQ...
  ```

- [ ] **4.5.** Повторить на сервере: `.env` в git не попадает, поэтому там значения дописываются руками.

  ```
  nano /opt/motivation/.env
  ```

---

## Этап 5. Проверка

```
cd tools
python threads_refresh_token.py --whoami
python threads_publish.py "Пробная строка" https://raw.githubusercontent.com/Zveren001/nika-media/main/motivation/<файл>.jpg
```

Первая команда подтвердит, что токен принят и привязан к нужному аккаунту, вторая опубликует пробный пост по готовой ссылке из хранилища.

Дальше Threads подхватывается сам: `autopost.py` публикует туда сразу после Instagram. Пустой `THREADS_ACCESS_TOKEN` просто пропускает шаг — расписание из-за этого не ломается.

---

## Что важно помнить

**Лимит текста — 500 символов**, против 2200 у Instagram. Цитаты короткие, в лимит укладываются с большим запасом, но скрипт всё равно обрежет длинное с многоточием.

**Хэштеги в тексте не кликабельны.** Threads принимает ровно одну тему на пост, отдельным полем. В Threads уходит чистый текст цитаты и тема `мотивация`, четыре инстаграмных хэштега туда не идут.

**Сбой Threads не ломает расписание.** Instagram публикуется первым, цитата помечается использованной независимо от Threads, ошибка попадает в лог. Пропущенный пост Threads не догоняется — следующий слот идёт своим чередом.

**Лимит публикаций — 250 постов в сутки**, ограничением не становится.

**Токен живёт 60 дней** и продлевается:

```
python threads_refresh_token.py
```

Срок совпадает с токеном Instagram — удобно продлевать оба в один день. И не забывать про сервер: там свой `.env`.
