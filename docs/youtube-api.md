# Автозагрузка роликов на YouTube

Ролики, уходящие в Instagram, тем же запуском отправляются на канал
[@MonoMotivation69](https://www.youtube.com/@MonoMotivation69). Картинки не отправляются —
на YouTube им нечего делать.

Вертикальное видео короче трёх минут YouTube сам относит к Shorts, отдельного
эндпоинта для них нет: используется обычный `videos.insert`.

## Про ограничение непроверенных приложений

В документации Google сказано, что видео от непроверенного приложения загружаются
заблокированными как private, и снимается это только
[аудитом](https://support.google.com/youtube/contact/yt_api_form).

**На практике 29.08.2026 оба ролика вышли публичными:** API вернул
`privacyStatus: public`, страницы открываются анонимно. Аудит не проходился,
приложение переведено в production без верификации.

Так что автоматика работает целиком. Но если однажды ролики начнут приходить
скрытыми — причина будет эта, и лечится она только аудитом.

## Блокировка аккаунта 30.08.2026 и восстановление

Через сутки после подключения Google заблокировал аккаунт `mono.motivation69@gmail.com`
с формулировкой «аккаунт создали или использовали со множеством других аккаунтов»
и «мог быть создан компьютерной программой».

**Апелляция удовлетворена за сутки, 31.08.2026 доступ вернули.** Важное наблюдение:
`refresh_token` пережил блокировку — после разблокировки он заработал снова,
перевыпускать не пришлось. Два ролика, вышедшие за время простоя только
в Instagram, догружены `youtube_backfill.py`.

Что, вероятно, сработало триггером: аккаунт был свежий, и почти сразу с него пошли
запросы к API с арендованного сервера в другой стране. Само по себе использование
API правил не нарушает, но связка «новый аккаунт плюс зарубежный сервер плюс
автозагрузки» для антифрода выглядит как бот.

**Вывод на будущее: канал лучше держать на давнем личном аккаунте с реальной
историей**, а не на заведённом под проект. Порог подозрительности у таких заметно выше.

На время блокировки `YT_REFRESH_TOKEN` в `.env` очищался — иначе каждая публикация
ролика тратила бы полминуты на заведомо неудачный запрос. Instagram это никак
не затронуло: за сутки простоя лента вышла полностью, включая ролики.

## Что настроено

| Что | Значение |
|---|---|
| Проект | `poised-rock-507006-u8` |
| API | YouTube Data API v3, включён |
| Тип доступа | OAuth 2.0, клиент типа Desktop |
| Право | `youtube.upload` |
| Ключи | `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` в `.env` |

Квота — 10 000 единиц в сутки, загрузка стоит 1600. При двух роликах в сутки
расходуется 3200, то есть треть. Запас есть даже на повторы после сбоев.

## Экран согласия обязан быть в Production

В Google Cloud Console: **APIs & Services → OAuth consent screen → Publishing status**.

**В режиме Testing Google отзывает refresh-токен через семь дней** — публикация
встанет через неделю с ошибкой доступа. Переключение в Production снимает это
ограничение; при авторизации появится предупреждение «приложение не проверено»,
его проходят через «Дополнительно» → «Перейти на страницу».

Переключать нужно **до** получения токена: иначе токен придётся выпускать заново.

## Получение токена

Один раз, на машине с браузером:

```
cd tools
python youtube_auth.py
```

Скрипт откроет согласие Google, поймает ответ на `localhost:8723` и запишет
`YT_REFRESH_TOKEN` в `.env`. Старый способ с показом кода на странице Google
отключил, поэтому и нужен локальный порт.

Дальше токен переносится на сервер: он в `.env`, а `.env` в git не попадает.

## Догрузка после простоя

```
python youtube_backfill.py --dry-run    посмотреть, что не загружено
python youtube_backfill.py              залить
```

Находит по журналу ролики без `youtube_id`, забирает файл из хранилища и заливает.
Повторный запуск уже загруженное не трогает, поэтому запускать можно свободно.

## Разовая загрузка вручную

```
python youtube_publish.py ../output/2026-08-29_06.mp4 "Текст цитаты"
```

Печатает ссылку и фактический уровень доступа — по нему сразу видно, сработало
ограничение непроверенного приложения или нет.

## Что уходит в описание

Заголовком идёт сама цитата, описанием — цитата плюс `#shorts #мотивация
#цитаты #саморазвитие`. Категория 22 («Люди и блоги»), пометка «сделано для
детей» снята.

## Изоляция

Без `YT_REFRESH_TOKEN` в `.env` блок YouTube молча пропускается — ровно как это
сделано с Threads. Сбой загрузки на YouTube не влияет на Instagram: ролик
публикуется первым, ошибка попадает в лог, следующий слот идёт своим чередом.
