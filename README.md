# Мотивационный аккаунт

Instagram-аккаунт с короткими мыслями на однотонном фоне. Публикация полностью автономна: сервер сам берёт следующую цитату, рисует картинку и выкладывает по расписанию.

**Аккаунт:** [@mono.motiv](https://instagram.com/mono.motiv)

## Как это устроено

Картинки **не генерируются нейросетью** — они рисуются программно за доли секунды: однотонный фон, текст по центру, автоподбор кегля под длину цитаты. Ни моделей, ни ожидания, ни отказов.

Фон чередуется строго: белый → чёрный → белый → чёрный. Счёт идёт по сквозному номеру публикации, поэтому порядок не сбивается при смене расписания или пропуске дня.

## Где работает

На VPS в Амстердаме, `/opt/motivation`. Cron запускает публикацию в 06:00 и 18:00 по Москве с пониженным приоритетом, чтобы не мешать VPN на той же машине.

Подробности — [docs/vps-setup.md](docs/vps-setup.md).

## База цитат

**1500 штук**, все уникальные, хватит на **750 дней** при двух постах в сутки.

Цитаты без авторства и намеренно нейтральные: никакой политики, религии, веществ. Тексты про свободу и границы — только в личном смысле, о работе и отношениях.

Пополнить базу:

```python
import add_quotes
add_quotes.add([("Текст цитаты", "тема")])
```

Дубли отсеиваются автоматически, тексты прогоняются через проверку на типовые огрехи. Проверить всю базу: `python add_quotes.py --lint`.

## Локальный запуск

```
cd tools
python render.py "Текст" 0 ../output/test.jpg   # 0 белый фон, 1 чёрный
python autopost.py --dry-run                    # что ушло бы, без отправки
```

Нужен Pillow: `pip install Pillow`.

## Состояние

| | |
|---|---|
| Цитат в базе | 1500 |
| Опубликовано | 1 |
| Режим | 2 поста в сутки, 06:00 и 18:00 |
| Хватит до | примерно два года |

Переход на четыре поста в сутки — одна строка в `.env`, когда аккаунт наберёт вес. Первые две недели держим два.
