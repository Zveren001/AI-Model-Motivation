Политика конфиденциальности

Приложение Mono.motiv · обновлено 29 августа 2026

Mono.motiv — служебное приложение, которое публикует подготовленные автором ролики на его собственный YouTube-канал. Оно не рассчитано на сторонних пользователей и не предоставляет им никаких функций.

Какие данные используются

Приложение работает только с аккаунтом Google своего владельца и запрашивает единственное разрешение:

  • YouTube Data API — загрузка видео (youtube.upload): нужно, чтобы выкладывать готовые файлы на канал владельца.

Никаких других данных аккаунта приложение не запрашивает: ни почту, ни контакты, ни историю просмотров, ни статистику.

Что хранится

На сервере владельца хранится токен доступа к его собственному аккаунту Google — он нужен, чтобы публикация шла по расписанию без ручного входа. Токен лежит в файле конфигурации, доступном только владельцу сервера, и не передаётся никому.

Персональные данные каких-либо третьих лиц не собираются, не хранятся и не обрабатываются.

Передача третьим лицам

Данные не продаются, не передаются и не раскрываются. Единственный внешний адресат запросов — сами сервисы Google, куда загружается видео.

Использование данных, полученных через Google API, подчиняется Политике Google API Services User Data, включая требования Limited Use.

Отзыв доступа

Владелец может в любой момент отозвать доступ приложения на странице Разрешения аккаунта Google. После отзыва публикация прекращается, а сохранённый токен становится недействительным.

Изменения

Если политика изменится, обновлённая версия появится на этой же странице с новой датой.
